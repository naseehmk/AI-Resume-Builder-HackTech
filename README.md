## 📌 About the Project

The **AI-Powered Resume Builder & Interview Prep Portal** is a fully browser-based web application that uses the **Google Gemini API** to help job seekers:

- Generate tailored, professional resumes in seconds
- Get AI-powered feedback on their resume content
- Practice for interviews with AI-generated questions based on their job role
- Download their resume as a polished PDF

No login required. No backend. Everything runs in the browser.

---

## ✨ Features

### 📄 Resume Builder
- Input personal details, skills, experience, and education
- AI generates a polished, ATS-friendly resume summary
- Multiple resume templates to choose from
- Download as PDF with one click

### 🎯 Interview Prep
- Enter your target job role and experience level
- AI generates role-specific interview questions
- Get model answers and tips for each question
- Practice mode with instant AI feedback

### 💡 AI Suggestions
- Real-time AI feedback on resume content
- Skill gap suggestions based on job role
- Action verb recommendations for stronger bullet points

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge)
- A free groq API key → [Get it here](https://console.groq.com/keys)

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/naseehmanikkoth/AI-Resume-Builder-HackTech.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd AI-Resume-Builder-HackTech
   ```

3. **Add your Gemini API key**
   - Open `js/gemini.js`
   - Replace `YOUR_API_KEY_HERE` with your actual Gemini API key

4. **Open `index.html` in your browser**
   - Or use Live Server in VS Code for the best experience
